Lectoire

Read, listen to, write and sell books in one app.

A book store, reader and library with an AI writing Studio and a Claude connector. One Next.js app on one MongoDB database.

Initial open-source release · 13 October 2026

The problem

Writing, reading and selling a book are usually separate products.

Each hand-off between them is work the author does by hand.

Write

Chat doesn't hold the pen

An AI chat can draft prose, but the author still copies it into a manuscript, chapter by chapter.

Read

Reading apps stop at reading

They carry other people's books. Turning your own idea into a book happens somewhere else.

Sell

Getting paid is its own project

A price, a checkout, refunds, payouts and printed copies each need their own setup.

The solution

One place for the whole life of a book.

Book Store

Genres, featured shelves, book pages with contents and similar titles.

Reader

Font controls, chapter nav, highlights, saved progress and narration.

Studio

Claude writes chapters, covers and pictures straight into the book.

Claude connector

12 MCP tools from Claude Code, Claude Desktop or claude.ai.

Plus

$5.99 a month for the Studio and every unpriced book.

Selling

Authors set a price and keep 70% of what is left after card fees.

Print

Readers order paperbacks; orders are fulfilled from the admin portal.

Downloads

EPUB, PDF, DOCX, HTML, Markdown and plain text in one ZIP.

Installs from the browser as a progressive web app on phones, tablets and desktops.

How it works · the Studio

In the Studio, the AI holds the pen.

Each message runs an agent loop on the server. Its tools write real chapters into MongoDB while the preview updates beside the chat.

Part of Plus · the reply is saved even if the tab closes mid-turn · the hand editor and the MCP tools use the same writers.

How it works · architecture

One server, one database, the rest optional.

Covers upload from the browser straight to the bucket with a presigned URL. Stripe calls back through a signed webhook.

How it works · money

A priced book is bought; the rest is in Plus.

Who can read a book, checked in this order

  1. The owneralways, draft or published
  2. A free bookanyone signed in
  3. A priced bookonly readers who bought it
  4. Everything elsePlus members, $5.99 a month

Where a $4.99 sale goes

$4.99

Earnings clear after 30 days, then authors withdraw from $25 through Stripe Connect Express.

Tech stack

A small stack that any Node host can run.

Web

Next.js 16 App Router, React 19, Tailwind CSS v4

Data

MongoDB with Mongoose 9, schemas in lib/models.ts

AI

Anthropic SDK with streaming and tool use; optional xAI images

Payments

Stripe Checkout, subscriptions and Connect Express

Auth

bcrypt and a jose JWT cookie; OAuth with PKCE for connectors

Media

Any S3-compatible bucket, presigned uploads, sharp

Files

pdfkit, docx, jszip and marked out; unpdf and mammoth in

Ship

Standalone build in a node:22-slim container, installable PWA

Required: MongoDB, an auth secret and an Anthropic key. Everything else switches itself off when its key is missing.
